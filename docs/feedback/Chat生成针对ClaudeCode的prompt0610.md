## 使用建议

1. **量化目标**：将模糊概念（慢节奏、氛围感）转为可验证条件。
2. **拆分模块**：每次修改只针对一个模块，避免信息干扰。
3. **提供原始内容和示例**：帮助 Claude Code 明确修改范围和目标。
4. **明确验证方法**：确保修改后可手动或自动验证。
5. **记录修改历史**：形成可追溯文档，方便后续迭代。
